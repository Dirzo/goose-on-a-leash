# Launch plan

Dates are placeholders; set them once the beta has run.

## Phases

1. **Now: playable web build.** The private playtest artifact and the Cloudflare URL once secrets are set.
2. **Closed beta (two weeks).** See `community.md`. Fix the top three faint rooms and the top two quit rooms.
3. **Steam page live.** Copy and capsules from `steam.md`, the teaser from `trailers.md`. Start collecting wishlists. Post the teaser to the Discord and socials.
4. **itch.io public demo.** Reedmarsh and Hollowbark, plus the Infinite Basement (it markets itself through the leaderboard).
5. **Next Fest (if timed).** Demo build, a stream of the Basement and the fishing.
6. **Launch.** Launch trailer, the full game on Steam and itch, a launch-day Discord event (Basement race).

## Launch-week checklist

- [ ] Final balance pass from beta stats (`docs/BALANCE.md`)
- [ ] All tests green in CI; size budget passing
- [ ] Save compatibility: an old save loads in the launch build
- [ ] Credits screen, version number on the title
- [ ] Press kit page: logo, 5 screenshots, the 30 s teaser, a one-paragraph description, contact
- [ ] Steam: store page, capsules, achievements, build uploaded to the default branch, release date set
- [ ] itch.io: page public, build uploaded, devlog post
- [ ] Discord: announcement drafted, roles ready
- [ ] Social posts scheduled: teaser, a fishing clip, a Basement clip
